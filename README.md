## D4.by — интернет‑магазин на OpenCart 2.3

Проект представляет собой кастомизированный интернет‑магазин на базе **OpenCart 2.3**, с основной бизнес‑логикой в модулях `admin` и `catalog`.

### Основное

- **Платформа**: OpenCart 2.3.x
- **Основные директории логики**:
    - `admin/` — административная панель, управление товарами, заказами и настройками
    - `catalog/` — витрина магазина, карточки товаров, корзина, оформление заказа
- **Назначение проекта**: реализация интернет‑магазина `d4.by` с доработанными модулями и шаблонами.

### Структура проекта

- `admin/` — контроллеры, модели и шаблоны админ‑части
- `catalog/` — контроллеры, модели и шаблоны клиентской части
- `system/` — ядро OpenCart, общие библиотеки и конфигурация
- `image/`, `download/` и др. — статические ресурсы и медиа

### Установка и запуск

1. Скопируйте файлы проекта на сервер (Apache/Nginx + PHP).
2. Настройте виртуальный хост и корневую директорию сайта.
3. Создайте базу данных MySQL/MariaDB.
4. Импортируйте дамп БД (если имеется) и пропишите настройки подключения в конфигурационных файлах OpenCart (`config.php`, `admin/config.php`).
5. Откройте сайт в браузере:
    - фронт: `http(s)://your-domain/`
    - админка: `http(s)://your-domain/admin/`

### Разработка

- Для доработок рекомендуется придерживаться стандартной структуры MVC OpenCart (controller / model / view).
- Перед коммитами проверяйте работу как в витрине, так и в админке.
